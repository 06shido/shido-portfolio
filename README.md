# SHIDO.exe — Portfolio

A responsive black-and-purple cyberpunk developer portfolio.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository (for example `shido-portfolio`).
2. Upload all files and folders in this project.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for the Pages URL to appear.

Update the GitHub and LinkedIn links in `index.html` before publishing if needed.
